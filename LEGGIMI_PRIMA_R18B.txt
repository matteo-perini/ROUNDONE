LIONFIT PATCH 30 R18B — INVITI GARE, ATTIVAZIONE PILOTA SAFE
===========================================================
Compatibile ESCLUSIVAMENTE con i sorgenti R18A forniti dall'utente il 18/11/2026, verificati tramite SHA256.
ESTRAI nella radice LionFit-Modern-Git (src e package.json visibili); NON estrarre l'archivio R18A diagnostico.

COSA FA
- Installer APPLICA_R18B.cmd: 5 file aggiornati, backup esterno automatico, verifica SHA256 prima e dopo.
- Non modifica Firestore Rules, dati, altre Cloud Functions, .env, APK e web; NON fa deploy.
- Impedisce inviti da palestre non abilitate: flag frontend e controllo server sulla palestra pilota.
- Backend non richiede email verificata per una funzionalita' riservata a utenti gia autenticati e membri attivi della palestra, ma mantiene controlli severi su ruolo, palestra, gara futura e progetto Firebase.
- Push ai soli destinatari creati per invito esplicito; usa 'open=bookings' compatibile con la navigazione push disponibile (apre l'Agenda, non sempre il dettaglio preciso).
- Le gare pubblicate da sole NON inviano push. La partecipazione spontanea rimane.

INSTALLA E VERIFICA
1. Backup della cartella funzionante.
2. Estrai lo ZIP R18B nella radice LionFit-Modern-Git, senza cartelle duplicate.
3. Doppio clic APPLICA_R18B.cmd.
4. Da PowerShell root:
   node --test tests/patch30-r18b-competition-pilot.unit.mjs
   node --test competitions-backend/functions/inviteModel.test.mjs
   node --check competitions-backend/functions/index.mjs
   npm.cmd run build
Nessuna publicazione finche' i controlli non sono tutti superati.

ATTIVAZIONE PILOTA (SOLO DOPO TEST; NON e' AUTOMATICA)
5. Da Firebase Console trova l'ID gym_... della TUA palestra di prova (users/<uid>.gymId), senza incollarlo a caso.
6. Nella root: node .\R18B_CONFIGURA_PILOTA.cjs backend gym_ID_REALE
   Il comando crea/aggiorna competitions-backend/functions/.env.app-palestra-b0b9d con:
   LF_COMPETITION_INVITES_ENABLED=true
   LF_COMPETITION_PROJECT_ID=app-palestra-b0b9d
   LF_COMPETITION_PILOT_GYM_ID=gym_ID_REALE
7. Apri terminale dentro competitions-backend:
   cd competitions-backend
   npm.cmd --prefix .\functions install
   npm.cmd --prefix .\functions test
   firebase.cmd deploy --only functions:competitions --project app-palestra-b0b9d
   firebase.cmd functions:list --project app-palestra-b0b9d
   Devono apparire lfCompetitionInvite e lfCompetitionRespond. NON dare conferme di cancellazioni inattese.
   Se ci sono avvisi di protezione o errori, fermati; NON tentare deploy generale.
8. Torna alla root: cd ..
   node .\R18B_CONFIGURA_PILOTA.cjs frontend gym_ID_REALE
   npm.cmd run build
   Soltanto se build OK prepara e pubblica l'app come di consueto.
9. TEST LIVE CON 1 PALESTRA E ACCOUNT DEMO: Coach invita A e NON B; solo A vede l'invito. A accetta/rifiuta, Coach vede risposta. B puo' comunque premere Voglio partecipare. Push solo se dispositivo registrato e permessi concessi.
10. Testa in sicurezza il caso altra palestra, evento cancellato, invito duplicato. Verifica non compaiano eliminazioni in deploy.

LIMITI E AVVISI
- Test locali qui effettuati: unit/statici, non Emulator Functions end-to-end e non test con FCM reale.
- Il codice pilota e' volutamente bloccato sulle altre palestre. Estensione globale: patch separata, solo dopo collaudo.
- Un push ricevuto e' best-effort e puo' non arrivare con notifiche disabilitate.
- Il tap apre Agenda tramite open=bookings; deep link alla singola gara non e' garantito dal push manager corrente.
- Non confondere il flag in .env.production.local con la distribuzione del backend.
- Non incollare o committare file .env o credenziali. Verifica git status.
- Le Firestore Rules di R17B restano invariate: il backend usa Admin SDK ma verifica in modo indipendente i ruoli.
- Il rollback ripristina solo i 5 file sorgente, non revoca Functions gia distribuite. Disabilita la flag su server/client prima di fare rollback se il backend e' stato attivato.

ROLLBACK
Esegui ROLLBACK_R18B.cmd con file non modificati dopo l'installazione. Ripristina originali da backup esterno, non tocca dati Firebase.
