COME INSTALLARE
1. Fare prima una copia di sicurezza dell'attuale LionFit-Modern-Git funzionante.
2. Estrarre TUTTI i file dello ZIP R15 nella RADICE (cartella principale) LionFit-Modern-Git.
   Devono apparire allo stesso livello di package.json e src:
   - APPLICA_R15.cmd, LionFit_R15_APPLICA.cjs, R15_ARCHIVIO.css, R15_ARCHIVIO_TEST.mjs
   - RIPRISTINA_R15.cmd, LionFit_R15_RIPRISTINA.cjs, LEGGIMI_R15.txt
3. Doppio clic su APPLICA_R15.cmd (una sola volta). Leggere il risultato.
4. Nella radice del progetto, PowerShell:
   node --test tests/patch30-r15-archive-experience.unit.mjs
   npm.cmd run typecheck
5. Se tutti i test superati, eseguire LIONFIT_PREPARA_WEB_E_DOCS.cmd e controllare che la build sia riuscita.
6. Solo dopo build riuscita usare GitHub Desktop, ispezionare modifiche, Commit e Push origin.
   Nel commit includi SOLO i file src/ modificati e il test tests/; non committare APPLICA_R15.cmd,
   i file R15_ARCHIVIO.*, gli script di installazione, file .env o backup del Desktop.
7. Controllare smartphone: Schede 7/7, ricerca, filtri, programmi conclusi, settimane, giorni e PDF/scheda.
