CAUSA INDIVIDUATA NEI SEI FILE FORNITI DALL'UTENTE
Quando readStagingSession() valorizza stagingSession.value, App.vue cambia
immediatamente il ramo del template da login a shell Coach/Atleta, anche se
la route e ancora /accesso. La smontatura di GoogleExistingSigninButton.vue
puo attivare il controllo if(!alive), che dopo signInWithCustomToken esegue
signOut() per sicurezza. Il risultato osservabile e il ritorno al login.

CORREZIONE
Modifica SOLO il ramo del template in src/App.vue:
  PRIMA: <template v-else-if="shownRole">
  DOPO: <template v-else-if="shownRole && route.path!='/accesso'">

Cosi la schermata di accesso resta montata fino a quando il callback Google
ha richiesto la navigazione verso la dashboard. La shell si attiva subito
dopo il cambio della route. Rimangono INVARIATI: verifica UID/email, controllo
ruolo/palestra, router, logout, Firestore Rules, backend, Control Center.

INSTALLAZIONE (cartella LionFit-Modern-Git sul desktop)
1. Estrai lo ZIP R21P in una cartella separata.
2. Copia le cartelle `tools` e `tests` dello ZIP NELLA CARTELLA PRINCIPALE
   LionFit-Modern-Git, unendo le cartelle gia esistenti, senza sostituire
   altri file di progetto.
3. Apri PowerShell nella cartella principale e lancia:

  cd "$env:USERPROFILE\Desktop\ULTIMA\LionFit-Modern-Git"
  node .\tools\applica-r21p.mjs
  node --test .\tests\r21p-login-shell.unit.mjs
  npm.cmd run build

Lo script installa la correzione a src/App.vue soltanto se l'hash coincide
ESATTAMENTE con quello dello ZIP fornito dall'utente. Su hash diverso si
ferma SENZA modificare il progetto. Prima di scrivere crea un backup in:
  Desktop\LionFit_R21P_BACKUP

SE CI SONO ERRORI: FERMA LA PUBBLICAZIONE e mostra l'output dei comandi.
Non rieseguire vecchie patch R21O o altri installer.

DOPO TEST E BUILD OK:
  .\LIONFIT_PREPARA_WEB_E_DOCS.cmd
  git status --short
Controllare che file .env/.secret e node_modules siano ignorati; poi fare
Commit + Push della build web attraverso GitHub Desktop.
NON eseguire firebase deploy: il backend Google e gia stato pubblicato.
